# Hardware IoT - Privlazy Door Project

This is the source code for **Privlazy Door**,  
a project created for the *Hardware* course in the 1st year of Computer Engineering studies.

## 📌 Project Description

This project involves an IoT-based smart door controller system that focuses on user access and privacy using hardware components.
